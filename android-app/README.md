# Aplikacja Android

Planowany stack: Kotlin, Jetpack Compose, Room, zadanie okresowe w tle (WorkManager), powiadomienia lokalne.

Zasady:

- dane portfela i strategii zostają na urządzeniu,
- aplikacja pobiera codziennie migawkę ofert i liczy strategię lokalnie,
- eksport i import danych użytkownika, systemowa kopia zapasowa wyłączona,
- logi nie zawierają kwot, banków ani strategii użytkownika.

Implementacja: Etap 9.
